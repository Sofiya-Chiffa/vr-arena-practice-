# VR-арена: процедурная реализация (КТ2)
Программа автоматизирует сеансовое обслуживание на арене виртуальной реальности: проверку заявки клиента, поиск свободных слотов, бронирование и закрытие брони с фиксацией проведённого сеанса.

## Сборка и зависимости

Программа написана на Python 3.14 с использованием только стандартной библиотеки.  
Внешних зависимостей нет, менеджер пакетов (`requirements.txt`, `pyproject.toml`) не требуется.

Отдельная сборка не нужна — Python-скрипты запускаются напрямую интерпретатором.  
Убедитесь, что установлен Python версии 3.14 или новее:

```bash
python --version
```
## Структура проекта
src/
 - main.py          точка входа, разбор аргументов командной строки 
 - operations.py    автоматизируемые операции (проверка, бронь, закрытие)
 - algorithms.py    два алгоритма: find_free_slots, validate_request 
 - data.py          загрузка и сохранение данных в JSON 
 - README.md
 - data/           Данные хранятся в JSON-файлах

# Запуск
Все команды выполняются из папки src/
Команды:
 - slots(дата) - показать свободные слоты на выбранную дату
 - check - демо-проверка заявки
 - book - демо-бронирование слота SL0003
 - close - закрыть бронь и создать сеанс

Примеры запуска:
```bash
cd src

python main.py slots 2026-11-10
python main.py check
python main.py book
python main.py close B0001 E0001
```
