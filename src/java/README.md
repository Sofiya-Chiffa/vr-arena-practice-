# VR-арена: объектно-ориентированная реализация (КТ3)

Программа автоматизирует сеансовое обслуживание на арене виртуальной реальности: проверку заявки клиента, поиск свободных слотов, бронирование и закрытие брони с фиксацией проведённого сеанса.

В отличие от КТ2, здесь программа реализована объектно-ориентированно на языке Java. Логика операций инкапсулирована в классах-сущностях.

## Сборка и зависимости

*Требования:*
- JDK 21 (или новее).
- Внешние зависимости и менеджеры пакетов (Maven/Gradle) не используются. Сборка выполняется стандартным компилятором `javac`.

```bash
java --version
```
# Структура проекта
 - /model - классы-сущности предметной области  
 - BookingService.java - Операция бронирования
 - SessionService.java - Операция закрытия брони и создания сеанса
 - SlotService.java - Алгоритм поиска свободных слотов
 - Validator.java - Алгоритм проверки заявки

# Сборка
Откройте терминал (PowerShell, командную строку или Git Bash) и перейдите в папку src/.  
Для Windows PowerShell:
```bash
javac -d out (Get-ChildItem -Recurse -Filter *.java | ForEach-Object { $_.FullName })
```
Для Git Bash / Linux / macOS:
```bash
javac -d out $(find . -name "*.java")
```
После успешной компиляции в папке src/ появится директория out/ со скомпилированными .class файлами.
# Запуск
Все команды выполняются из папки src/.

Запуск осуществляется через класс ConsoleApp, который принимает аргументы командной строки (аналогично main.py из КТ2).
Команды:

    slots (дата) — показать свободные слоты на выбранную дату

    check — демо-проверка заявки

    book — демо-бронирование слота SL0003

    close — закрыть бронь и создать сеанс
Примеры запуска:
```bash
java -cp out ConsoleApp slots 2026-12-10
```
Вывод:  
Свободные слоты на 2026-12-10:
SL0003  12:00
SL0004  13:30
```bash
java -cp out ConsoleApp check
```
Вывод:  
Заявка корректна
```bash
java -cp out ConsoleApp book
```
Вывод:
Бронь создана
Бронь B0001 (клиент C0001, слот SL0003, статус ACTIVE)
```bash
java -cp out ConsoleApp close B0001 E0001
```
Сеанс проведён, услуга оказана
Сеанс S0001 (2026-11-20 15:30 — 2026-11-20 16:30)
